# 🗄️ Database Documentation

Direktori ini berisi skema database SQL, migrasi, dan data awal (*seeds*) untuk aplikasi To-Do List jika Anda ingin menghubungkannya dengan relational database (seperti MySQL, PostgreSQL, atau SQLite).

## Struktur Files

- `schema.sql`: Definisi tabel utama.
- `migrations/`: Script migrasi versi database.
- `seeds/`: Data sampel awal.
